    Quick start & AOT workflow

    Create an application with the included starter:

    npx --package @mpeliz/gtplweb gtpl-init my-app --yes
cd my-app
npm install
npm run build:dev
npm run server

    Open http://localhost:8080. For an existing app, install @mpeliz/gtplweb. TypeScript projects enable experimentalDecorators.

    import { Component, GTplComponentBase } from '@mpeliz/gtplweb';

@Component({
  tag: 'hello-card',
  template: './HelloCard.html',
  style: './HelloCard.scss',
  styleMode: 'inline'
})
export class HelloCard extends GTplComponentBase {
  name = 'GTPLWeb';
}

    HelloCard.html contains <h2>Hello {{ name }}</h2>. Import the component module before using <hello-card></hello-card>.

    gtpl-aot compiles templates and styles into src-aot; gtpl-app-build --mode dev also runs the AOT step before bundling. Use --mode bundle for a production bundle. See the CLI reference for configuration.

    This playground uses bundled local framework code and inline JIT templates for immediate demos. Source panels use JavaScript's Component(config)(Controller), equivalent to TypeScript's @Component(config). The examples are predefined trusted templates.

    API & practical notes

    APIPurpose
    Component(config)Register a controller. The tag must contain a hyphen. Import each component module once.
    GTplComponentBaseOptional lifecycle hooks plus injected $el and destroy().
    g-set:property.pathAssign an input to a child component's controller. Initialize intermediate objects in the child.
    g-classReplace classes from an array or a space-separated string.
    g-componentMount a registered component by tag; switching destroys its previous controller.
    GBus.subscribe / emitCoordinate components through events and namespaces. Release subscriptions in onDestroy().
    GRouterService.init(routes)Start shared application routing. Hash mode is the default; router changes emit urlChanged in the router namespace.
    GRouter.matchPath(path)Resolve route patterns without navigation. Supports parameter matching, regex validation and middleware.

    Removing a native element triggers onDisconnect(); call its controller's destroy() when permanently disposing it. g-component handles replacement cleanup. Keep documentation anchors separate from an application's hash router.
